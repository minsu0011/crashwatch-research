# 공식 소스 접근 주소

- KRX Data Marketplace: https://data.krx.co.kr/
- pykrx 1.2.8: https://pypi.org/project/pykrx/1.2.8/
- 금융위원회 주식대차거래정보 API: https://www.data.go.kr/data/15124865/openapi.do
- OpenDART: https://opendart.fss.or.kr/
- OpenDART 인증키 신청/관리: https://opendart.fss.or.kr/uss/umt/EgovMberInsertView.do
- 한국은행 ECOS Open API: https://ecos.bok.or.kr/api/
- FRED: https://fred.stlouisfed.org/

인증정보는 사이트에서 직접 발급하고 `.env.data.local`에만 입력한다.
